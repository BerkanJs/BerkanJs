<h2>🧠 What I Build</h2>

<p><b>⚙️ Event-Driven Backends</b><br/>
High-volume event ingestion with Redis Streams and consumer groups — horizontal scaling, backpressure, at-least-once delivery, two-layer deduplication with idempotency, dead-letter queues for poison-pill messages, and bulk writes to TimescaleDB via the COPY protocol.
</p>

<p><b>🖥️ Frontend Architecture</b><br/>
Next.js App Router with React Server Components and SSR prefetching, a Zod-validated data layer with typed errors, TanStack Query caching, real-time updates over SSE, and modular domain-driven codebases with config-driven layouts.
</p>

<p><b>🔐 Security & Access Control</b><br/>
DPoP-bound authentication, JWT with refresh-token rotation, multi-layer RBAC with declarative permission registries, Content-Security-Policy, and rate limiting.
</p>

<p><b>🎨 Design Systems & Data Visualization</b><br/>
Token-based component libraries on Radix UI and Tailwind CSS with dark mode, plus interactive analytics — heatmap, sankey, treemap and time-series charts.
</p>

<p><b>🤖 Real-Time AI & Communication</b><br/>
LLM integrations with live AI avatars, custom model engines and LLM-based evaluation pipelines; peer-to-peer audio/video with WebRTC.
</p>

<p><b>✅ Testing & Quality</b><br/>
Unit, component and E2E testing with Jest, React Testing Library and Playwright, automated accessibility checks in CI, and API integration tests with Supertest.
</p>

<p><b>🌌 3D & Motion</b><br/>
Immersive web experiences with Three.js and GSAP — scroll-driven 3D scenes and cinematic landing pages.
</p>
